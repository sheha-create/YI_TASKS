# Northstar Responsive Landing Page

A polished, responsive landing page concept built with semantic HTML5, modern CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — visual system, responsive layout, and media queries
- `script.js` — accessible mobile navigation and dynamic footer year
- `wireframe.md` — layout plan and wireframe notes

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. Resize the browser or use Developer Tools device emulation to test desktop, tablet, and mobile layouts.

No package installation, framework, build step, or API key is required.

## Features
- Semantic landmarks: header, navigation, main, sections, articles, and footer
- Responsive CSS Grid and Flexbox layouts
- Mobile navigation toggle with `aria-expanded`, `aria-controls`, and accessible labels
- Keyboard focus indicators and skip-to-content link
- Reduced-motion preference support
- Responsive type using `clamp()`
- Inline CSS illustration, so no external image downloads are required

## Design note
Northstar is a fictional digital-workspace concept created for this assignment. The contact call-to-action uses a demo `mailto:hello@example.com` address and should be replaced if a real contact destination is required.
