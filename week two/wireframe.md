# Wireframe: Brightside FAQ Accordion

1. **Header**
   - Brand mark and product name on the left
   - Short descriptor on the right

2. **Intro / hero**
   - Eyebrow label
   - Large heading with highlighted phrase
   - Supporting description
   - Three feature indicators: accessible, responsive, dependency-free

3. **Accordion card**
   - Small section label and title
   - Expand all / Collapse all button
   - Instructions
   - Four FAQ rows, each with a number, question, and chevron
   - Answer panel below each trigger
   - Live status count

4. **Keyboard tip**
   - Keyboard icon
   - Short keyboard interaction instructions

5. **Footer**
   - Product label and current year

## Responsive behavior
- Desktop: centered card with generous whitespace.
- Mobile: narrower page gutters, smaller type, and compact accordion rows.
- Motion: panel reveal animation is disabled/reduced when the user's system requests reduced motion.
